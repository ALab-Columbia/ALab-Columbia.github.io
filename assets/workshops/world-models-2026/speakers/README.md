# Speaker portrait photos

Upload the six speaker headshots **here**, in `assets/workshops/world-models-2026/speakers/`.

Use **exactly** these lowercase JPEG filenames:

- `oumayma-bounou.jpg` — Oumayma Bounou (NYU)
- `stephen-tu.jpg` — Stephen Tu (USC)
- `adam-block.jpg` — Adam Block (Columbia)
- `yunzhu-li.jpg` — Yunzhu Li (Columbia)
- `rohun-agrawal.jpg` — Rohun Agrawal (Columbia)
- `ying-wang.jpg` — Ying Wang (NYU)

**How to add:** Click **Add file → Upload files** in this GitHub folder, upload the photos, and commit. The [workshop page](https://alab-columbia.github.io/workshops/world-models-2026/) loads matching filenames automatically and otherwise displays the speaker's initials.

Use actual JPEGs with the `.jpg` extension. No code edits necessary.

For the talk and group photos, use [../story/](../story/). See [the full photo guide](../README.md).
