# Mini-Workshop photo story

Upload photos from the talks and group discussion **here**, in `assets/workshops/world-models-2026/story/`.

## Exact filenames

Use lowercase JPEGs with **two-digit consecutive numbers**:

```
photo-01.jpg
photo-02.jpg
photo-03.jpg
photo-04.jpg
...
photo-30.jpg
```

**Start at 01 and do not skip numbers.** The website automatically loads `photo-01.jpg`, then `photo-02.jpg`, and stops when the next photo does not exist. You only need to upload the files; no code edit is needed. You can add up to 30 photos.

Tip: upload in chronological order (speakers, conversations, discussion). If you want meaningful captions instead of the default “Workshop photo 01,” edit the `storyCaptions` object in [the workshop page source](../../../workshops/world-models-2026/index.html) (or see [the main photo guide](../README.md)).

To upload, click **Add file → Upload files**, select your `.jpg` files, and commit. Please make sure the photos may be shared publicly.
